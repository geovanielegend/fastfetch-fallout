# fallout theme for fastfetch
<o>to install use</p><br>
<p>cd ~/.config/fastfetch</p><br>
 <p></p>wget https://github.com/geovanielegend/fastfetch-fallout</p><br>
<p></p>Setup is simple, change your CLI background to any black color and the text to green #1EDE23</p>
<p>You can change the</p><p style="color: green;"> hammer.txt</p> <p>source to any other txt files I have included or make your own</p><br>
<p>>Adjustments will need to be made in config.jsonc</p><br>
<pre><code class="language-javascript">
    "padding": {
      "top": 1,
      "left": 3
    }
</code></pre><br>
<p>larger ascii pictures will need lower top/left margin while smaller ones will need larger numbers to center them better.</p>
