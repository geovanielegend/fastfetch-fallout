# fallout theme for fastfetch
<p>to install use</p>
<figure>
  <figcaption>Terminal Session</figcaption>
  <pre>
<span class="prompt">user@host:~$</span> <kbd>cd ~/.config/fastfetch</kbd>
<span class="prompt">user@host:~$</span> <kbd>wget https://github.com/geovanielegend/fastfetch-fallout</kbd>
<span class="prompt">user@demo:~$</span> <kbd>_</kbd>
  </pre>
</figure>
<p>Setup is simple, change your CLI background to any black color and the text to green #1EDE23</p>
<p>You can change the hammer.txt source to any other txt files I have included or make your own</p>
<p>>Adjustments will need to be made in config.jsonc</p><br>
<pre><code class="language-json">
    "padding": {
      "top": 1,
      "left": 3
    }
</code></pre><br>
<p>larger ascii pictures will need lower top/left margin while smaller ones will need larger numbers to center them better.</p>
